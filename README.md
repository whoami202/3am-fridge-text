The 3AM Fridge Text — a program that writes the one line a smart fridge would text its owner at 3am: "It's 3am. I saw the 2am sandwich. I saw the 2:30 sandwich. I'm keeping a list."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
